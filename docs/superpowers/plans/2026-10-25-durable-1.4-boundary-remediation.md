## Design decisions that constrain implementation

1. Keep actual runner response `{ id, type: "response", command, success, data/error }`. No `ok`/payload wire wrapper. Commands preserve message/images/conversationId and policy/binding/state operations. Additive fields are allowed.
2. Canonical IPC modules own Zod schemas and inferred types. Producer and consumer import them; runner/bridge/contracts.ts may retain narrow named type compatibility exports while actual owners move, but no second independently editable event model. Inventory stdout events AND bridge FD3 frames before closing decoder work; notices/subagent frames must not be accidentally classified unknown.
3. Unknown discriminants: bounded diagnostic counter/trace and skip; never dump their type/payload. Known invalid packet: typed protocol error, not normal event and not silently pending until timeout.
4. Correlate a broken response only to a validated outstanding request ID with matching command. A valid numeric conversation ID must resolve through actual bindings before targeting a child. If neither correlation is trustworthy, fail pending transport requests and surface channel-health failure, not a fabricated parent/child terminal outcome; require explicit recovery rather than replay a prompt. Tests must distinguish transport failure from native task failure. Do not guess missing IDs.
5. Error records expose fixed component/operation/code/category and safe IDs only. Keep original Error.cause internally, never emit raw JSON, prompt, arbitrary error.message/type or secrets. Unknown-type diagnostics are rate-limited; Notice supports info/warning/error, not invented debug.
6. Mirror adoption is a pure decision over a small immutable snapshot. A host use-case owns state transitions/registration/buffer draining through a narrow port. Router maps the decision; no transport context swapping or full PiThreadSession dependency disguised as helper.
7. Runtime subscription owner owns conversation replacement, unsubscribe/dispose and task attachment; failed acquisition keeps previous binding valid; close is idempotent; stale subscription callbacks do not update current state. Native Durable owns lifecycle, not this read binding.
8. Keep the manual rollout amendment: no mandatory production-backup pipeline, no automatic hot handoff; this work does not install/reload/quit anything. Final bump is 0.2.x and push remote as now explicitly requested. Tag/release/installed-provider update remains separate from that push.
